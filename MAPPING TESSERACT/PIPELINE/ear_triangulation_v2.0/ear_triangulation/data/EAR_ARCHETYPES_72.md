## §HOW TO READ

Each cell is Σ_DAXP where:
- D (1-4): dimension (linear, planar, volumetric, temporal)
- A (1-3): attribute (1=Δ distinction, 2=⇄ relation, 3=⟳ process)
- X (1-3): complexity (1=foundational, 2=recursive, 3=synthetic)
- P (+/-): polarity (expansion/contraction)
