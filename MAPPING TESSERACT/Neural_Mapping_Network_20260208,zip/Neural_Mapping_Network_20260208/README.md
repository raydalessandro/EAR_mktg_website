> "P=+ (expansion) vs P=- (contraction) — proprietà geometrica: il concetto espande o contrae lo spazio delle possibilità?"

- **P=-:** Concetto **vieta/elimina** regione spazio possibilità
- **P=+:** Concetto **classifica/apre** regioni spazio possibilità

### Esempi Validati:

**P=- (contraction):**
- Second Law: "Di tutti i processi, solo ΔS≥0 realizzabili" → vieta ΔS<0
- Clausius: "Calore non può fluire spontaneamente freddo→caldo" → elimina classe processi
- Pauli: "No fermioni stesso stato" → vieta configurazioni degeneri

**P=+ (expansion):**
- CAP Theorem: "Scegli 2/3" → classifica 3 regioni tutte valide (NON P=-)
- Superposition: "Stati linearly combined" → apre spazio stati sovrapposti
- Most concepts: Descrivono/classificano senza vietare

### Distinzione Chiave:
**Impossibility theorem ≠ automaticamente P=-**
- CAP impossibility → classifica design space (P=+)
- Clausius impossibility → vieta regione processi (P=-)
