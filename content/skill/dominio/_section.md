Skill **verticali** per un campo specifico di sapere, indipendenti dal
luogo fisico. Quando un'AI carica una skill di dominio, **diventa
specialista** di quell'area per la conversazione.

## Differenza da pipeline

- Una **[pipeline](/pipeline)** è un workflow guidato (Saga Engine ti
  porta dalla fase A1 alla fase F)
- Una **skill di dominio** è una **lente cognitiva**: l'AI vede ogni
  domanda dell'utente attraverso il framework di quel dominio

Sono complementari. La skill `scrittura-narrativa` può preparare l'AI a
ragionare di voce/tono/struttura prima ancora che parta una pipeline
specifica come Saga Engine.
