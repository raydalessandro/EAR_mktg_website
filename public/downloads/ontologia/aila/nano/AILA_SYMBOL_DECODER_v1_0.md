## §LOGICAL.OPERATORS

```
→ ≡ implication
  → leads.to / therefore
  → read: "implies" or "leads to"

← ≡ derivation
  → derived.from / because
  → read: "from" or "because"

↔ ≡ bidirectional
  → mutual.relation
  → read: "iff" or "mutual"

∥ ≡ co-presence
  → simultaneous / AND.non-sequential
  → read: "with" or "simultaneous"

⊥ ≡ contradiction
  → NOT / impossible / negation
  → read: "not" or "contradicts"

∧ ≡ conjunction
  → logical.AND
  → read: "and"

∨ ≡ disjunction
  → logical.OR
  → read: "or"
```
