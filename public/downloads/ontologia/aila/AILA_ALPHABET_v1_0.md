## §PREAMBLE

```
◉purpose
  → AILA uses 64 functional signs organized in 11 layers.
  → Each sign has exactly one primary meaning.
  → No sign is redundant; removing any one reduces expressive capacity.
  → This document is the definitive reference for AILA notation.

◉design.principle
  → AILA is NOT a natural language alphabet.
  → AILA is an operational notation system for ontological structures.
  → It restores to explicit signhood what ancient alphabets encoded
    implicitly and what modern alphabets lost:
    → the dicibility of process (⟳)
    → the dicibility of relation (⇄)
    → the dicibility of distinction (Δ)
  → Where ancient Hebrew used 22 letters as operators on 10 Sephiroth,
    and Arabic used 28 letters with triconsonantal roots,
    AILA uses 64 signs across 11 functional layers.

◉count
  → 64 signs total
  → 11 functional layers
  → + 72 composite addresses (Σ_DAXP) derived from 4 indices
  → + 22 Hebrew letters (referenced in §TRANSITIONS, not AILA-native)
```

## §STRUCTURAL.ANALYSIS

```
◉why.64
  → 64 = 2⁶
  → minimum complete binary decomposition at 6 levels of depth
  → sufficient to express all EAR constructs without ambiguity
  → no observed case where a 65th sign was needed

◉layer.architecture
  → Layers 1-3 (11 signs): WHAT EXISTS — ontological content
  → Layers 4-8 (27 signs): HOW IT RELATES — operational grammar
  → Layer 9 (16 signs): WHAT WE MEASURE — parametric space
  → Layers 10-11 (10 signs): HOW WE WRITE — meta/formatting

◉comparison.with.historical.alphabets
  | System      | Signs | Encodes                             |
  |-------------|-------|-------------------------------------|
  | Hebrew      | 22    | states + transitions (implicit)     |
  | Arabic      | 28    | states + transitions (more explicit)|
  | Greek       | 24    | states (transitions lost)           |
  | Latin       | 23    | states (transitions further lost)   |
  | Italian     | 21    | states (minimal transitions)        |
  | AILA        | 64    | entities + operations + measures    |

  → AILA does not replace natural language alphabets.
  → AILA operates at a different level:
    natural languages encode speech → AILA encodes ontological structure.
  → The 11 ontological signs (Layers 1-3) correspond functionally
    to what the 3 Mother Letters encoded in Hebrew:
    Aleph (Δ/distinction), Mem (⇄/relation), Shin (⟳/process).
  → AILA makes explicit what Kabbalah encoded esoterically
    and what Sufism encoded through initiatic science of letters.
```

## §USAGE.RULES

```
◉rule.1.completeness
  → Any EAR statement can be written using only these 64 signs
    plus ASCII alphanumerics for proper names and values.

◉rule.2.no.synonyms
  → Each sign has exactly one primary meaning.
  → No two signs mean the same thing.
  → When in doubt, consult this document.

◉rule.3.composability
  → Signs combine freely according to AILA grammar (AILA_LINGUA_v1.0).
  → Complex statements are built by composition, not by adding signs.

◉rule.4.stability
  → This alphabet is FROZEN at version 1.0.
  → New signs require a new version number and formal justification.
  → Removal of signs is prohibited (would break existing documents).
  → Addition is permitted only if no existing composition can express
    the needed meaning.

◉rule.5.encoding
  → All signs are standard Unicode.
  → No private-use-area characters.
  → Any system that supports UTF-8 can display AILA.
```
